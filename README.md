## 🎮 주요 기능

- **8종의 개성 넘치는 고양이들**: 치즈냥이, 턱시도, 고등어태비, 실버태비, 샴, 러시안블루, 까만고양이, 삼색냥이 등 다양한 종의 고양이들이 테트리스 블록으로 무작위로 등장합니다.
- **15+ 콤보 폭발 시스템**: 같은 종의 고양이 블록이 15개 이상 가로나 세로로 맞닿으면 시원하게 폭발하며 높은 보너스 점수를 획득할 수 있습니다. 
- **연쇄 반응(Chain Reaction) 및 중력**: 블록이 터지거나 한 줄이 지워지면 위에 떠 있던 블록들이 중력에 의해 빈 공간으로 떨어집니다. 이를 이용해 폭발적인 연속 작용을 유도해 통쾌한 콤보를 만들어보세요!
- **고양이 수집 도감 (Encyclopedia)**: 게임을 플레이하며 각 고양이별로 부순 블록의 누적 개수가 기기에 안전하게 영구 기록됩니다. 종별로 각각 만 개(10,000개) 이상의 블록을 부수게 되면 도감의 블러 처리가 걷히며 화면 가득 예쁜 모습이 수집(등록)됩니다!
