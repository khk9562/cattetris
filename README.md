> **냥스택 (NYANG STACK)** - 귀여운 고양이들을 쌓아서 터뜨리는 캐주얼 블록 퍼즐입니다!

## 🎮 주요 기능

- **12종의 개성 넘치는 고양이들**: 치즈냥이, 턱시도, 고등어, 실버태비, 샴, 러시안블루, 까망이, 삼색이에 흰냥이 오드아이, 카오스, 벵갈, 스코티시 폴드가 더해졌습니다. 난이도에 따라 한 판에 4~7종이 등장합니다.
- **고양이 뭉치 폭발**: 같은 종의 고양이가 기준 개수(하 10 / 중 12 / 상 13) 이상 맞닿으면 팡 터지고, 주변 8방향 한 칸의 블록까지 종에 상관없이 함께 날아갑니다.
- **난이도 상/중/하**: 낙하 속도, 락 딜레이, 등장 품종 수, 폭발 기준, 점수 배율이 달라지며 최고 기록은 난이도별로 저장됩니다.
- **표준 조작감**: SRS 회전, 7-bag, 락 딜레이, 홀드, 다음 조각 3개, 하드 드롭. 보드를 끌어서 이동하고 아래로 튕겨 하드 드롭, 탭으로 회전할 수 있습니다.
- **스테이지 모드 30개**: 줄/폭발/품종/연쇄/점수 목표와 조각·시간 제한, 별 3개 도전.
- **오늘의 미션과 칭호**: 매일 바뀌는 미션 3개를 완료하면 칭호를 받고 시작 화면에 표시됩니다.
- **살아 있는 고양이들**: 깜빡이고, 줄이 지워지면 웃고, 스택이 높아지면 겁먹고, 터지면 어지러워하고, 게임오버엔 잠듭니다. 폭발은 캔버스 파티클로 그립니다.
- **소리와 진동**: 에셋 없이 Web Audio로 합성한 효과음과 칩튠 배경음, 진동 피드백. 설정에서 각각 끌 수 있습니다.
- **튜토리얼**: 첫 실행 시 실제 보드에서 7단계로 조작과 팡 규칙을 배웁니다.
- **스킨과 액세서리**: 품종별 색 변형 24종은 도감 누적 수로, 리본/방울/안경/왕관은 스테이지 별로 해금됩니다.
- **PWA**: 홈 화면에 추가하면 오프라인에서도 실행됩니다.
- **연쇄 반응(Chain Reaction) 및 중력**: 블록이 터지거나 한 줄이 지워지면 위에 떠 있던 블록들이 중력에 의해 빈 공간으로 떨어집니다. 이를 이용해 폭발적인 연속 작용을 유도해 통쾌한 콤보를 만들어보세요!
- **고양이 수집 도감 (Encyclopedia)**: 게임을 플레이하며 각 고양이별로 부순 블록의 누적 개수가 기기에 안전하게 영구 기록됩니다. 종별로 500마리 이상을 터뜨리면 도감의 블러 처리가 걷히며 화면 가득 예쁜 모습이 수집(등록)됩니다!
